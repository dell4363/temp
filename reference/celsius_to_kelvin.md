# Μετατροπή Celsius σε Kelvin

Δέχεται μια τιμή σε βαθμούς Κελσίου και την μετατρέπει σε Kelvin.

## Usage

``` r
celsius_to_kelvin(celsius)
```

## Arguments

- celsius:

  Αριθμητική τιμή σε βαθμούς Κελσίου.

## Value

Η θερμοκρασία σε Kelvin.

## Examples

``` r
celsius_to_kelvin(0)
#> [1] 273.15
celsius_to_kelvin(25)
#> [1] 298.15
```
